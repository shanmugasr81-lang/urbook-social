# Reference reels → urbook reels

Folders: `parking/reels/instagram`, `parking/reels/tiktok`, `holiday/reels/instagram`, `holiday/reels/tiktok`.

**Shan adds** links to the `links.md` file in the right folder – one line each:
`- <link> – <what I liked: hook / story / edit / music / offer>`

**The social learner (Claude)**, at each run:
1. Opens each new link read-only in Shan's Chrome (or reads the caption Shan pastes) – never downloads, re-uploads or screenshots it into our content.
2. Writes `notes.md` in the same folder: account, hook (first 3 s, on-screen text), story arc, shot changes, length, CTA, why it works, the matching formula in `hooks.json`, and a ✅/❌ safety check (legal, Meta/TikTok-safe, fits urbook rules).
3. Turns ✅ ideas into a urbook brief (`/ig-reel`) using **our own** footage – copy the formula, never the video, wording or audio.
4. Marks the link `– used <date>` in `links.md`.

## How references reach the agents (25 Nov 2026)
Instagram blocks automatic reading and downloading from the cloud, so:
1. **Shan picks a reel** → screen-records it on his iPhone and sends the recording to Claude in chat (the GitHub app can't upload videos), plus the link in links.md if he likes.
2. **Claude studies it** (frames, on-screen text, pacing, sound), writes the formula into `notes.md` in the same folder and marks the link read. The recording itself is never committed or posted.
3. Links without a recording: Claude reads them in Shan's Chrome at the next session.
4. **The social learner reads every notes.md each run**, and once a week runs vidIQ outlier search (UK travel / Heathrow parking, last 30 days) to find new patterns itself – text and numbers only, formula never the video.
